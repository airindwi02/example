# Catatan Rancangan Tambahan: Pesanan Barang Owner

Referensi `.design-reference/owner` berisi 26 layar dan tidak menyertakan halaman pemesanan. Halaman `/owner/pesanan` karena itu merupakan tambahan rancangan sementara berdasarkan token visual, typography, sidebar, tabel, panel, badge, dan dialog Owner saat ini. Halaman lama tidak diubah secara visual.

Konfirmasi asisten praktikum masih diperlukan untuk penambahan menu/halaman, istilah status, aturan pembatalan, serta susunan field pemasok, tanggal, jumlah, dan harga. Form sementara mensyaratkan harga positif; jika barang gratis/FOC harus didukung, aturan itu perlu dikonfirmasi dan disesuaikan. Aturan permission sementara tercatat di `PERMISSION-MATRIX-ORDER-PROPOSAL.md`.
